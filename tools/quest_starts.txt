# Точки старта не начатых квестов (этап 3a) — исходник для tools/gen_quest_starts.py.
# Отобрано вручную по вики fallout.fandom.com (инфобокс «given by» + описание начала квеста)
# и сверено с Fallout4.esm/DLC (tools/esm_index.py, tools/quest_starts_research.py).
#
# Строка: <EDID квеста> <ref квестодателя> [after=<EDID>[,<EDID>...]] [radio=<радиус>]  # комментарий
#   ref    — "Plugin.esm|XXXXXX" (локальный FormID размещённого NPC/объекта) или EDID ref'а.
#   after  — квест(ы), которые должны быть завершены, иначе квестодатель квест не даёт.
#   radio  — ref — радиопередатчик: квест начинается, когда игрок ловит его сигнал; радиус приёма
#            (XRDO, тип «радиус») в единицах игры. Цель маркера: «послушать радио <станция>».
#   after=A|B,C — «A или B», и C.
#   objective=N — квест начат, когда показана цель N (у квеста может быть несколько строк: по ref на цель).
#   stage=N     — квест начат, когда пройдена стадия N (квест без целей в Pip-Boy).
#   inside      — к ref нет пути через двери (Институт — только телепорт): точки на карте нет, старт
#                 предлагается, только когда ref загружен рядом с игроком.
#   running     — квестодатель предлагает квест, только пока квест УЖЕ работает: реплики лежат в топиках
#                 самого квеста, а запускает его Story Manager (вход в локацию, событие вербовки и т.п.).
#                 Если рядом с квестодателем квест не работает (не заполнился обязательный алиас — чаще
#                 всего локацию держит другой квест), DLL пишет «временно недоступен» и старт пропускает.
#                 Кандидаты считает tools/quest_starts_running.py.
#   closed=K    — старт закрыт, пока фракция K враждебна игроку (изгнали: Братство, Подземка, Институт — после
#                 выбора другой фракции; Минитмены — после рейдов в Нюка-Мире; Фар-Харбор, Акадия, Дети Атома).
#                 Ключи и FormID — CLOSED в tools/gen_quest_starts.py. В окне «враждебна фракция …», F1 пропускает.
# У квеста может быть несколько строк (несколько квестодателей / передатчиков) — выбирается ближайшая доступная.
#
# Не включены (решение 2026-09-30, пересмотрено 2026-10-01 по списку ru-вики — полный разбор с причинами:
# _research\nqt-quests\quest_starts_coverage.md, невозможные — quest_starts_impossible.md):
#   - радиантные и повторяемые квесты, основной сюжет и основные цепочки фракций/DLC (приходят сами
#     из предыдущего квеста; побочные квесты фракций включены с after);
#   - радио, слышное везде (Automatron, Ядер-Мир, Волт-Тек, Радио Свободы): игра сама показывает
#     в Pip-Boy цель «послушать радио»; радио, которое переносят в случайное место (Shipbreaker).
#   - NPC сам подходит к игроку (Эдвард Диган — «Особая доставка», Перл — «Смерть мозга»);
#   - unmarked-квесты (нет записи в Pip-Boy) — пока; с полем stage=N их можно добавить;
#   - квесты спутников по симпатии, «Свадьба».
