# Nearest Quest Tracker — новое меню настроек (предложение на проверку)

Цель: один хоткей «Отметить ближайшее» вместо отдельных хоткеев на каждый вид цели. Что он выбирает,
задают переключатели. Отметки: **[новое]**, **[было: …]** — что было раньше, **[убрать?]** — убрать предлагаю я,
решаете вы.

---

## Было (сейчас в игре) — 19 пунктов

| Раздел | Пункт |
|---|---|
| — | текст «Нажмите хоткей, чтобы отметить…» |
| Хоткеи | Отметить ближайший квест · Показать ближайший новый квест · Исключить отмеченный квест · Вернуть последний исключённый |
| Настройки | Снимать отметку с остальных · Уведомления · Автоматически · Учитывать не начатые квесты · Учитывать квесты без маркера · Без спойлеров |
| Исключённые квесты | текст-пояснение · Вернуть квест (список) · Вернуть все |
| Локации | текст-пояснение · Ближайшая неоткрытая локация (хоткей) · Исключить отмеченную локацию (хоткей) · Все локации (спойлеры) |
| Исключённые локации | Вернуть локацию (список) · Вернуть все локации |

Что здесь лишнее:
- Хоткей «Показать ближайший новый квест», хоткей локаций и переключатель «Учитывать не начатые квесты» делают одно и то же:
  выбирают, **среди чего** искать. Их заменят переключатели «Что выбирать».
- Два хоткея «Исключить…» (квест и локация) отличаются только видом цели. Хватит одного: он исключает то, что отмечено.
- Два списка исключённого с двумя кнопками «Вернуть все» можно свести в один общий список.
- Три текста-пояснения (вверху, у исключённых, у локаций) повторяют подсказки к пунктам. Оставить один короткий вверху.

## Станет (с ответами пользователя 2026-10-04)

**Текст вверху:** «Хоткей отмечает ближайшую цель: квест из Pip-Boy, начало нового квеста или неоткрытую локацию —
что включено ниже. Сначала цели мира, где вы сейчас, потом Содружества, Фар-Харбора и Ядер-Мира.»

### Хоткеи
| Пункт | Что делает |
|---|---|
| **Отметить ближайшее** [было: «Отметить ближайший квест», «Показать ближайший новый квест», «Ближайшая неоткрытая локация»] | Ставит маркер на ближайшую цель из включённых в «Что выбирать». Повторное нажатие снова отмечает ближайшую (ничего не снимает). |
| **Исключить отмеченное** [было: два хоткея «Исключить…»] | Исключает то, что отмечено сейчас (квест, новый квест или локацию), и отмечает следующее ближайшее. |
| Вернуть последнее исключённое [было: «Вернуть последний исключённый»] | Возвращает последнее исключённое, какого бы вида оно ни было (квест, новый квест, локация), и снова отмечает ближайшее. |

### Что выбирать **[новое]**
| Пункт | По умолчанию | Что делает |
|---|---|---|
| **Выбирать активные квесты** **[новое]** | вкл. | Квесты из Pip-Boy с маркером. |
| — Квесты без маркера [было: «Учитывать квесты без маркера»] | выкл. | Квесты из Pip-Boy без маркера («найди сам»), после квестов с маркером в том же мире. Действует, только когда включены активные квесты. |
| **Выбирать новые квесты** [было: «Учитывать не начатые квесты» + хоткей «Показать ближайший новый квест»] | выкл. | Места, где начинаются ещё не начатые квесты (квестодатели). |
| — Без спойлеров [было там же] | выкл. | Маркер нового квеста не называет квест. |
| **Выбирать неоткрытые локации** [было: хоткей «Ближайшая неоткрытая локация»] | выкл. | Локации карты, которые вы ещё не открыли. Поселения пропускаются. |
| — Все локации (спойлеры) [было там же] | выкл. | Выкл.: только локации на вашей карте или компасе. Вкл.: любые неоткрытые, с названием. |

Если все три «Выбирать…» выключены, хоткей говорит «Ничего не выбрано — включите в настройках».

### Настройки
| Пункт | По умолчанию | Что делает |
|---|---|---|
| Только один маркер [было: «Снимать отметку с остальных»] | вкл. | Остаётся один маркер: при новой отметке остальные квесты, маркер нового квеста и маркер локации снимаются. |
| Автоматически | выкл. | Ближайшее отмечается само, когда выполнена цель, начат квест или открыта отмеченная локация. |
| Уведомления | вкл. | Без изменений. |

### Исключённое **[было: два раздела]**
| Пункт | Что делает |
|---|---|
| Вернуть (список) | Один общий список: «Квест: …», «Новый квест: …», «Локация: …». Выбранный пункт возвращается в поиск. |
| Вернуть всё | Очищает весь список. |
| Вернуть активные квесты **[новое]** | Возвращает только исключённые квесты из Pip-Boy. |
| Вернуть новые квесты **[новое]** | Возвращает только исключённые не начатые квесты. |
| Вернуть локации **[новое]** | Возвращает только исключённые локации. |

Выполненные квесты и открытые локации уходят из списка сами, как сейчас.

## Решения пользователя (2026-10-04)

1. Хоткей «Вернуть последнее исключённое» **оставить**: он возвращает последнее исключённое любого вида.
   В меню кнопки «Вернуть всё», «Вернуть активные квесты», «Вернуть новые квесты», «Вернуть локации» (без хоткеев).
2. Цели разных видов в одном мире — **все вперемешку по расстоянию**.
3. «Снимать отметку с остальных» снимает и маркер нового квеста, и маркер локации: **маркер один**.

4. «Отметить ближайшее» **всегда отмечает ближайшую цель** (вперемешку), та же она или другая — повторное нажатие
   ничего не снимает. С «Только один маркер» (бывшее «Снимать отметку с остальных») все остальные маркеры убираются.
5. Общий выпадающий список «Вернуть» **оставить** рядом с четырьмя кнопками.
