# Nearest Quest Tracker

Мод для Fallout 4: по хоткею отмечает квест из Pip-Boy, маркер которого ближе всего к игроку, и снимает
отметку с остальных — на компасе остаётся один маркер. Ещё может поставить маркер на ближайшее место, где
начинается ещё не начатый квест.

English - [README.md](README.md).

## Возможности

Хоткеи (назначаются в MCM, страница *Nearest Quest Tracker*; по умолчанию не назначены):

- **Отметить ближайший квест** — отмечает квест Pip-Boy с ближайшим маркером. Пункты «Разного» тоже
  участвуют; в уведомлении тогда текст цели.
- **Показать ближайший новый квест** — маркер на ближайший старт ещё не начатого квеста (квестодатель,
  записка, радиопередатчик, место). Цель называется «Новый квест: <название>» и пропадает, когда квест
  начался. 99 точек старта для основной игры, Far Harbor и Nuka-World лежат в
  `F4SE\Plugins\NearestQuestTracker\QuestStarts.json`.
- **Исключить отмеченный квест** — мод больше не отмечает этот квест и отмечает следующий ближайший.
  Квест уходит из списка исключённых, когда выполнен.
- **Вернуть последний исключённый**. В MCM есть и весь список исключённых: вернуть любой или все сразу.

Настройки:

| Настройка | По умолчанию | |
|---|---|---|
| Снимать отметку с остальных | ВКЛ | хоткей снимает отметку со всех остальных квестов |
| Уведомления | ВКЛ | называют отмеченный квест |
| Автоматически | ВЫКЛ | ближайший квест отмечается сам, когда выполнена цель или начался новый квест |
| Учитывать не начатые квесты | ВЫКЛ | «Отметить ближайший» учитывает и точки старта и ставит маркер, если старт ближе |
| Учитывать квесты без маркера | ВЫКЛ | отмечаются и квесты, у целей которых нет маркера, — после квестов с маркером |
| Без спойлеров | ВЫКЛ | у маркера старта написано только «Новый квест» |

Тексты на русском или английском — по `sLanguage` игры.

## Как работает

Папирус не умеет перечислять квесты Pip-Boy и позиции их целей, поэтому основную работу делает
F4SE-плагин `NearestQuestTracker.dll` (исходники в `f4se_plugin/`, CommonLibF4). Сведения о движке ниже —
из дизассемблирования `Fallout4.exe` 1.10.163 с его PDB.

- **Расстояние.** Для каждой показанной цели квеста движок хранит путь от игрока
  (`PlayerCharacter::questTargets`, `TeleportPath` через двери) и перестраивает его раз в несколько секунд —
  по нему ведёт маркер компаса. Мод меряет этот же путь, так что квест за дверью находится на расстоянии
  пешего пути до него, а не по прямой.
- **Порядок по мирам.** Кандидаты сравниваются по мирам: сначала мир игрока, потом Содружество,
  Фар-Харбор, Ядер-Мир, остальные миры. Внутри мира — по расстоянию; квесты без маркера (если включено) —
  после квестов с маркером. Мир интерьера — мир маркера карты его локации, как на карте Pip-Boy.
- **Отметка** — `Quest.SetActive`, как кнопка «отслеживать» в Pip-Boy; выполненные квесты (даже консолью)
  пропускаются.
- **Старты квестов.** `QuestStarts.json` собирает `tools/gen_quest_starts.py` из списка, написанного
  вручную (`tools/quest_starts.txt`), и индекса мастеров (`tools/esm_index.py`). У каждой точки — квест,
  ref, где он начинается, и для квестодателя, который в памяти только при загруженной ячейке, —
  неподвижная точка и persistent-ref (обычно наружная дверь), куда ставить маркер. Старт считается взятым,
  когда квест показал цель (или указанную цель / стадию). Старты в другом мире меряются через собственные
  пути движка в этот мир.
- **Маркер старта.** В плагине есть скрытый квест «Разного» `NQT_StartMarkerQuest`, цель которого
  указывает на алиас; скрипт переносит алиас на ref старта, DLL переписывает текст цели.
- **Автоматический режим** раз в 2 секунды сверяет хеш показанных целей и переотмечает, когда он изменился.

### Свои точки старта

Скопируйте `QuestStarts-user.example.json` в `QuestStarts-user.json` в той же папке и добавьте старты
квестов из других модов (или поправьте ванильный). Формат описан в самом файле-примере.

## Требования

- Fallout 4 **1.10.163** (до Next-Gen). Next-Gen и Anniversary Edition пока не поддерживаются: DLL
  опирается на раскладку структур движка, проверенную только на 1.10.163, и на других версиях ничего не делает.
- [F4SE](https://f4se.silverlock.org/) 0.6.23.
- [Address Library for F4SE Plugins](https://www.nexusmods.com/fallout4/mods/47327).
- [Mod Configuration Menu](https://www.nexusmods.com/fallout4/mods/21497) — хоткеи мода сделаны через MCM.

Плагин `NearestQuestTracker.esp` с флагом ESL, единственный мастер — `Fallout4.esm`.

## Сборка

Клонировать с подмодулем (`git clone --recursive`). Нужны Visual Studio 2026 (18) с её CMake и vcpkg,
Python 3, компилятор Papyrus из Creation Kit в папке игры.

```
python tools/build.py --release     # DLL, NearestQuestTracker.esp, файлы MCM, скрипты Papyrus
python tools/deploy.py --dll release
python tools/package.py 1.0.0       # release\NearestQuestTracker-1.0.0.zip
```

`build.py` и `deploy.py` берут путь к игре из `FO4_PATH` (по умолчанию `D:\Games\Fallout 4`).
