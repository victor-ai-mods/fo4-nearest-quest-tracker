# Nearest Quest Tracker

Мод для Fallout 4: одна клавиша ставит маркер на ближайшее, куда стоит пойти, — ближайшую цель квеста из Pip-Boy,
начало ещё не начатого квеста, неоткрытую локацию или здание, где вы не были, — и убирает остальные маркеры. Окно
показывает все квесты по категориям и все неоткрытые места; управление мышью, клавиатурой и геймпадом.

English - [README.md](README.md).

## Известные проблемы: мод глючный

И полностью это не исправить:

- **Невозможно отследить все условия, при которых квест можно взять.** Они разбросаны по репликам, сценам,
  триггерам и скриптам игры, у каждого квеста свои. Поэтому маркер нового квеста иногда ведёт к квестодателю, у
  которого квест сейчас не взять (спит за запертой дверью, ещё рано, сначала нужно другое). Такую цель можно
  исключить одной клавишей. С версии 2.1 мод сам распознаёт самые частые случаи — см. «Старты, которые сейчас не
  взять» ниже.
- **Сами квесты в Fallout 4 часто глючат**: иногда квесты не хотят начинаться, а иногда не хотят заканчиваться.
  Мод показывает то, что даёт игра, и эти ошибки тоже.

## Возможности

**Отметить ближайшее** ставит маркер на ближайшую цель и убирает остальные маркеры. Что считать целью, задаётся в
MCM:

- **Квесты из Pip-Boy**, в том числе пункты «Разного»; по желанию — и квесты без маркера.
- **Новые квесты** — места, где начинаются ещё не начатые квесты: квестодатель, записка, радиопередатчик. 98 точек
  старта для основной игры, Фар-Харбора и Ядер-Мира. Режим «Без спойлеров» не пишет название квеста у маркера.
- **Квестодатели радиантных квестов** — Престон Гарви, проктор Квинлан, капитан Келс, ПАМ, доктор Каррингтон,
  учёные Института и другие (33 повторяемых квеста), но только пока у квестодателя действительно есть для вас
  задание: условия его реплики-предложения проверяет сам движок игры.
- **Неоткрытые локации** — на карте или на компасе, по желанию любые. Поселения пропускаются.
- **Интерьеры, где вы не были** — здания, подвалы, пещеры; маркер ставится на дверь снаружи. Двери, которым нужен
  ключ, и, по желанию, чужие запертые двери пропускаются.

**Старты, которые сейчас не взять**, не выбираются, а в окне показаны с причиной:

- **нужное квесту место держит другой квест.** Некоторые квесты игра запускает в фоне (при входе в локацию), и
  квестодатель предлагает их, только если квест уже идёт. Если нужное им место зарезервировано другим квестом, они
  не стартуют. Пример: «Старый город в новом цвете» Эббота не начнётся, пока «Квартирмейстер» держит Хозмаг, —
  окно называет мешающий квест. Указатели на такие квесты («Поговорить с Эбботом у стены») тоже не выбираются;
- **фракция враждебна** — вас изгнали из Братства, «Подземки» или Института, минитмены после рейдов в Ядер-Мире,
  Фар-Харбор, Акадия, Дети Атома. Читается настоящее состояние фракции, поэтому если мод сохраняет фракцию
  дружественной, её квесты остаются;
- **квестодатель враждебен** вам (напали, розыск, враждебная фракция).

Расстояние до квеста — **по маршруту маркера компаса, через двери**, а не по прямой. Сначала цели мира, где вы
сейчас, потом Содружества, Фар-Харбора и Ядер-Мира.

**Окно** (игра на это время на паузе):

- Вкладка **«Квесты»**: дерево категорий, как на Fallout Wiki (основные, фракционные, побочные, дополнения, квесты
  других модов), со счётчиками «выполнено/всего»; квесты с миром, расстоянием и состоянием (в Pip-Boy, можно
  начать, не начат, выполнен, мешает другой квест, враждебна фракция или квестодатель, запущен игрой, но не взят —
  с местом, которое он держит). Фильтры: состояние, «только с маркером», мир.
- **Поиск по части названия**: клавиша F (как поиск FallUI в торговле), набор текста, Enter — применить, Esc —
  сбросить.
- Вкладка **«Локации»**: неоткрытые локации и интерьеры, где вы не были. Фильтры: замеченные / все, локации /
  интерьеры, мир.
- Щелчок по строке ставит маркер; кнопка в строке исключает цель или возвращает её. Мышь, клавиатура и геймпад
  (подсказки внизу окна).
- Открывается хоткеем, кнопкой в MCM или предметом **«Nearest Quest Tracker»** («Помощь», ничего не весит):
  положите его в избранное — и окно открывается одной кнопкой геймпада. После использования предмет возвращается в
  инвентарь.

Хоткеи (MCM, страница *Nearest Quest Tracker*; по умолчанию не назначены): **Отметить ближайшее**, **Исключить
отмеченное** (отмечает следующее ближайшее; выполненные квесты, открытые локации и посещённые интерьеры уходят из
списка исключённого сами), **Вернуть последнее исключённое** (в MCM есть и весь список), **Показать текущий
квест** (отслеживаемый квест и что сейчас нужно сделать), **Вкл/выкл автоматический режим**, **Открыть окно**.

Настройки:

| Настройка | По умолчанию | |
|---|---|---|
| Выбирать активные квесты | ВКЛ | квесты Pip-Boy с маркером |
| Квесты без маркера | ВЫКЛ | и квесты Pip-Boy без маркера — после квестов с маркером |
| Выбирать новые квесты | ВЫКЛ | точки старта ещё не начатых квестов |
| Выбирать квестодателей радиантных квестов | ВКЛ | квестодатели повторяемых квестов, пока у них есть для вас задание |
| Без спойлеров | ВЫКЛ | у маркера нового квеста написано только «Новый квест» |
| Выбирать неоткрытые локации | ВЫКЛ | локации карты, которые вы ещё не открыли |
| Все локации (спойлеры) | ВЫКЛ | любые неоткрытые, а не только на карте или компасе |
| Выбирать интерьеры | ВЫКЛ | интерьеры, где вы не были |
| Пропускать чужие запертые | ВКЛ | пропускать интерьеры за запертой дверью, взлом которой — преступление |
| Только один маркер | ВКЛ | хоткей убирает все остальные маркеры |
| Автоматически | ВЫКЛ | ближайшая цель отмечается сама, когда выполнена цель, начат квест, открыта локация или вы вошли в интерьер |
| Уведомления | ВКЛ | называют отмеченную цель |
| Текущий квест — в окне | ВЫКЛ | «Показать текущий квест» — окном сообщения, а не уведомлениями |

Тексты на русском или английском — по `sLanguage` игры.

## Как работает

Папирус не умеет перечислять квесты Pip-Boy и позиции их целей, поэтому основную работу делает
F4SE-плагин `NearestQuestTracker.dll` (исходники в `f4se_plugin/`, CommonLibF4). Сведения о движке — из
дизассемблирования `Fallout4.exe` 1.10.163 с его PDB; подробности в `PLAN-1.0.md` и `PLAN.md` («Решения и находки»).

- **Расстояние.** Для каждой показанной цели квеста движок хранит путь от игрока
  (`PlayerCharacter::questTargets`, `TeleportPath` через двери) и перестраивает его раз в несколько секунд —
  по нему ведёт маркер компаса. Мод меряет этот же путь, так что квест за дверью находится на расстоянии
  пешего пути до него, а не по прямой. Старты, локации и интерьеры в другом мире меряются через собственные пути
  движка в этот мир. Дочерние миры со своими координатами (Даймонд-Сити) переводятся в координаты родительского.
- **Порядок по мирам.** Сначала мир игрока, потом Содружество, Фар-Харбор, Ядер-Мир, остальные. Внутри мира — по
  расстоянию; квесты без маркера (если включено) — после квестов с маркером.
- **Отметка** — `Quest.SetActive`, как кнопка «отслеживать» в Pip-Boy. Маркеры старта и локации — скрытые квесты
  «Разного» в плагине (`NQT_StartMarkerQuest`, `NQT_LocationMarkerQuest`), цель которых указывает на алиас; скрипт
  переносит алиас, DLL переписывает текст цели.
- **Старты квестов.** `QuestStarts.json` собирает `tools/gen_quest_starts.py` из списка, написанного вручную
  (`tools/quest_starts.txt`), и индекса мастеров (`tools/esm_index.py`).
- **Старты, которые не взять.** У квеста, который должен уже идти, чтобы его предложили, проверяется обязательный
  алиас локации: не держит ли её резервирующий алиас другого работающего квеста (`TESQuest::FindLocForAlias` для
  конкретной локации проверяет только резервирование, а не «зачищено»). Враждебность фракции — движковая
  `TESFaction::GetPCAnEnemy` и боевое отношение фракции к `PlayerFaction`; враждебность квестодателя —
  `Actor::CalculateFactionFightReaction`, а пока его нет в памяти — фракции его базового NPC.
- **Квестодатели радиантов.** Реплики-предложения квестодателя (их находит `tools/radiant_offers_research.py`)
  проверяются через `TESConditionItem::IsTrue` — субъект квестодатель, цель игрок, квест реплики в области
  видимости — пока этот квест идёт.
- **Категории.** `QuestCategories.json` собирает `tools/gen_quest_categories.py` из таблиц квестов Fallout Wiki;
  квесты, которых на вики нет, попадают в «Другие квесты», по подкатегории на плагин.
- **Локации** — маркеры карты всех миров (их флаги «видна» / «можно перемещаться»); **интерьеры** — по туману
  войны локальной карты Pip-Boy (`ExtraSeenData` ячейки, хранится в сохранении): ничего не открыто — значит, не были.
- **Окно** — своё меню Scaleform (`menu/NQTMenu.as`, в SWF его компилирует JPEXS FFDec), регистрируется через
  `UI.RegisterCustomMenu` из F4SE. Списки берёт у DLL через Scaleform-интерфейс F4SE
  (`f4se.plugins.NearestQuestTracker`), действия отправляет скрипту через `SendExternalEvent`.

### Свои старты и категории

Скопируйте `QuestStarts-user.example.json` / `QuestCategories-user.example.json` (в
`F4SE\Plugins\NearestQuestTracker`) в `QuestStarts-user.json` / `QuestCategories-user.json` и добавьте квесты
других модов. Формат описан в самих файлах-примерах.

## Требования

- Fallout 4 **1.10.163** (до Next-Gen). Next-Gen и Anniversary Edition пока не поддерживаются: DLL
  опирается на раскладку структур движка, проверенную только на 1.10.163, и на других версиях ничего не делает.
  Версия для AE планируется (`PLAN-AE.md`), срок не обещаю.
- [F4SE](https://f4se.silverlock.org/) 0.6.23.
- [Address Library for F4SE Plugins](https://www.nexusmods.com/fallout4/mods/47327).
- [Mod Configuration Menu](https://www.nexusmods.com/fallout4/mods/21497) — хоткеи и настройки.

Плагин `NearestQuestTracker.esp` с флагом ESL, единственный мастер — `Fallout4.esm`. Ванильные записи не меняет.

## Сборка

Клонировать с подмодулем (`git clone --recursive`). Нужны Visual Studio 2026 (18) с её CMake и vcpkg,
Python 3 с Pillow, компилятор Papyrus из Creation Kit в папке игры, JPEXS FFDec и Java (для SWF окна; `FFDEC_JAR`,
по умолчанию `..\_tools\ffdec_26.3.0\ffdec-cli.jar`), исходники Papyrus из F4SE 0.6.23 (`F4SE_SCRIPTS`, по умолчанию
`..\_tools\f4se_0_06_23\Scripts\Source`).

```
python tools/build.py --release     # DLL, NearestQuestTracker.esp, файлы MCM, SWF окна, скрипты Papyrus
python tools/deploy.py --dll release
python tools/package.py 2.0.0       # release\NearestQuestTracker-2.0.0.zip
```

`build.py` и `deploy.py` берут путь к игре из `FO4_PATH` (по умолчанию `D:\Games\Fallout 4`).
