# Nearest Quest Tracker

A Fallout 4 mod: press a hotkey and the mod tracks the Pip-Boy quest whose marker is closest to you, and
untracks the others, so the compass shows one marker. It can also put a marker on the nearest place where
a quest you have not started yet begins.

Русское описание - [README.ru.md](README.ru.md).

## Features

Hotkeys (set them in MCM, page *Nearest Quest Tracker*, none bound by default):

- **Track nearest quest** - tracks the Pip-Boy quest with the closest marker. Misc objectives count too;
  the notification then names the objective.
- **Show nearest new quest** - puts a marker on the nearest start of a quest you have not started yet (a quest
  giver, a note, a radio transmitter, a place). The marker reads "New quest: <name>" and goes away once the
  quest starts. 99 start points for the base game, Far Harbor and Nuka-World ship in
  `F4SE\Plugins\NearestQuestTracker\QuestStarts.json`.
- **Exclude tracked quest** - the mod will not track this quest any more and tracks the next nearest one.
  A quest leaves the exclusion list when it is completed.
- **Restore last excluded quest**. MCM also lists all excluded quests to take any one back, or all at once.

Settings:

| Setting | Default | |
|---|---|---|
| Untrack other quests | on | the hotkey untracks every other quest |
| Notifications | on | names the quest that is now tracked |
| Automatic | off | tracks the nearest quest by itself whenever an objective is completed or a new quest starts |
| Include quests not started | off | "Track nearest quest" also considers quest starts and marks one if it is closer |
| Include quests without a marker | off | quests whose objectives have no marker are tracked too, after the ones with a marker |
| No spoilers | off | a start marker says just "New quest" |

Texts are in English or Russian, by the game's `sLanguage`.

## How it works

Papyrus cannot list the Pip-Boy quests or the positions of their objectives, so the work is done by an
F4SE plugin, `NearestQuestTracker.dll` (source in `f4se_plugin/`, CommonLibF4). Engine details below come
from disassembling `Fallout4.exe` 1.10.163 with its PDB.

- **Distance.** For every displayed quest target the engine keeps a path from the player
  (`PlayerCharacter::questTargets`, a `TeleportPath` that goes through doors) and rebuilds it every few
  seconds - this is what the compass marker follows. The mod measures that same path, so a quest behind a
  door is as far as the walk to it, not the straight line.
- **Order by world.** Candidates are compared world by world: the player's world first, then the
  Commonwealth, Far Harbor, Nuka-World, other worlds. Within a world - by distance; quests without a marker
  (if enabled) come after the ones with a marker. The world of an interior is the world of its location's
  map marker, as on the Pip-Boy map.
- **Tracking** is `Quest.SetActive`, the same as the Pip-Boy track button; quests that are completed (even
  by the console) are skipped.
- **Quest starts.** `QuestStarts.json` is generated by `tools/gen_quest_starts.py` from the hand-written list
  `tools/quest_starts.txt` and an index of the masters (`tools/esm_index.py`). Each start has the quest, the
  reference where it begins and, for a quest giver who is in memory only while their cell is loaded, a fixed
  point and a persistent reference (usually the outer door) to aim at. A start counts as taken once the quest
  shows an objective (or the given objective/stage). Starts in another world are measured through the
  engine's own paths into that world.
- **Start marker.** The plugin has a hidden misc quest, `NQT_StartMarkerQuest`, whose objective points at an
  alias; the script moves the alias onto the start reference and the DLL rewrites the objective text.
- **Automatic mode** polls a hash of the displayed objectives every 2 seconds and re-tracks when it changes.

### Your own quest starts

Copy `QuestStarts-user.example.json` to `QuestStarts-user.json` in the same folder and add starts for quests
from other mods (or fix a vanilla one). The format is explained inside the example file.

## Requirements

- Fallout 4 **1.10.163** (pre-Next-Gen). Next-Gen and Anniversary Edition are not supported yet: the DLL
  relies on engine structure layouts checked on 1.10.163 only and does nothing on other versions.
- [F4SE](https://f4se.silverlock.org/) 0.6.23.
- [Address Library for F4SE Plugins](https://www.nexusmods.com/fallout4/mods/47327).
- [Mod Configuration Menu](https://www.nexusmods.com/fallout4/mods/21497) - the hotkeys are MCM hotkeys.

The plugin `NearestQuestTracker.esp` is ESL-flagged; its only master is `Fallout4.esm`.

## Building

Clone with the submodule (`git clone --recursive`). Visual Studio 2026 (18) with its CMake and vcpkg,
Python 3, the Creation Kit's Papyrus compiler in the game folder.

```
python tools/build.py --release     # DLL, NearestQuestTracker.esp, MCM files, Papyrus scripts
python tools/deploy.py --dll release
python tools/package.py 1.0.0       # release\NearestQuestTracker-1.0.0.zip
```

`build.py` and `deploy.py` take the game path from `FO4_PATH` (default `D:\Games\Fallout 4`).
